Drop your sample chart screenshots in this folder — .png, .jpg, .jpeg, or .webp.

The /samples command reads whatever is in here automatically (no code changes needed).
Filenames don't matter, but naming them clearly helps you keep track, e.g.:
  trending-chart.png
  ranging-chart.png
  chart-with-rsi-macd.png

Keep it to 3-5 good examples — the command sends a max of 5 to avoid spamming the chat.
